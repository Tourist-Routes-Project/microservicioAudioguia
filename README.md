# Microservicio de Audioguía

Este repositorio contiene el desarrollo de un **microservicio de audioguía** utilizando **Node.js** y **Express** como backend, con **MongoDB** como base de datos.

## Descripción

El proyecto tiene como objetivo desarrollar un microservicio que gestiona audioguías. El servicio permitirá almacenar, recuperar y gestionar las audioguías a través de una API RESTful.

## Tecnologías

- **Node.js**: Entorno de ejecución de JavaScript del lado del servidor.
- **Express**: Framework para la creación de APIs RESTful.
- **MongoDB**: Base de datos NoSQL para almacenar la información de las audioguías.
